# The Residence, Costa del Este

Sitio web estático para un complejo de departamentos frente al mar en Costa del Este: el complejo, departamentos, servicios, actividades, tarifas y un formulario de contacto.

**Stack:** HTML, CSS y JavaScript sin frameworks. Publicado en Vercel.

🔗 **En vivo:** [the-residence.vercel.app](https://the-residence.vercel.app)

## Estructura

```
index.html        → inicio
pages/            → complejo, departamentos, servicios, actividades, tarifas, resultado del formulario
css/  js/  img/   → estilos, script del sitio e imágenes
```
